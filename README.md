# IRON CROWN（初期版 0.1.0）

スマートフォンのブラウザで遊ぶ、リアル志向のボディビル大会 育成シミュレーション。
12週間の準備（トレーニング・食事・休養・日焼け・衣装）→ 大会前日の最終準備 → 大会（ライバル5人と採点）→ 結果。

## 起動

```
npm.cmd install
npm.cmd run dev        # http://localhost:5191 （同じWi-Fiのスマホからは表示される Network の URL）
npm.cmd run build      # dist/ に出力（相対パスなのでどこに置いても動く）
npm.cmd run preview    # ビルド結果の確認
npm.cmd test           # ルール・採点・メッシュのテスト
```

## 構成

| ファイル | 役割 |
|---|---|
| `src/body/anatomy.ts` | 骨格と約100個の形状（骨格の芯・筋肉・脂肪）。部位の発達・体脂肪率・左右差・張り・体格から形を作る |
| `src/body/poses.ts` | 6ポーズ（腕脚は向きで指定し、肘・膝のヒンジを自動計算） |
| `src/body/mesher.ts` | SDF の格子評価 → Surface Nets で表面メッシュ、法線・AO・基準姿勢座標 |
| `src/body/bodyWorker.ts` | メッシュ生成をワーカーで実行 |
| `src/body/viewer.ts` | three.js 表示。肌色・日焼け・色ムラ・ツヤ、トランクス（カット・素材・柄）をシェーダーで反映 |
| `src/game/data.ts` | 種目・商品・衣装・カテゴリー規定・ライバル・金額 |
| `src/game/rules.ts` | 週の進行の計算を一元管理（筋肉・体重・体脂肪・疲労・ケガ・張り・日焼け・所持金） |
| `src/game/scoring.ts` | 採点式（項目別 0〜100 × カテゴリー別比重）と結果の分析 |
| `src/game/store.ts` | localStorage 保存（端末内のみ） |
| `src/ui/app.ts` | 画面（タイトル／選手登録／選手／練習／食事／ショップ／日焼け・衣装／大会準備／結果） |

## 3D 人体について

利用条件を確認できる筋肉変形対応の人体モデル（glTF）が手元に無いため、外部アセットは使わず、
解剖学的な位置に置いた筋肉形状を滑らかに結合する方式（SDF）で人体を生成している。
数値が変わると形が実際に変わる（筋肉の厚み・広背筋の広がり・体脂肪による輪郭のぼやけ・腹部の脂肪）。
写真のようなリアルさ（皮膚の質感・顔の造形）は無く、彫像に近い見た目。

大会規定（カット・素材・体重上限）と採点式は本作オリジナルで、実在団体の規則ではない。
